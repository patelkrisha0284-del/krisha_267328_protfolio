# 🌸 Krisha Patel – Personal Portfolio Website

Welcome to my personal portfolio website! 👋

I am **Krisha Patel**, a Diploma in Information Technology student at the College of Technology, Aditya Silver Oak University, Ahmedabad, Gujarat.

This portfolio website is designed to introduce myself, showcase my technical skills, highlight my projects, and provide my contact information.

## 🌐 About the Project

The Personal Portfolio Website is developed using HTML, CSS, and JavaScript. It has a clean, modern, and responsive design that works on both desktop and mobile devices.

The main objective of this project is to present my educational background, technical knowledge, internship experience, and development projects in one place.

## ✨ Features

- Home section with personal introduction.
- About Me section.
- Technical Skills section.
- Projects section with project examples.
- Education details.
- Internship and work experience.
- Contact information.
- Contact form with input validation.
- Responsive design for mobile and desktop.
- Mobile navigation menu.
- Smooth scrolling and hover effects.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, animations, and responsive design.
- **JavaScript** – Mobile navigation and contact form validation.
